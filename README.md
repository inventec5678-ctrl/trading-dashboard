# 💎 加密貨幣報價儀表板

即時顯示 Top 30 加密貨幣報價，自動更新。

## 功能

- 💰 即時報價（每秒更新）
- 📊 30 種加密貨幣
- 🎨 精美 UI 設計
- ⚡ 快速載入

## 安裝

```bash
git clone https://github.com/inventec5678-ctrl/trading-dashboard.git
cd trading-dashboard
pip install -r requirements.txt
python server.py
```

## 使用

開啟瀏覽器：http://localhost:9001

## 技術

- 後端：Python
- 前端：HTML/CSS/JavaScript
- 數據：Binance API
